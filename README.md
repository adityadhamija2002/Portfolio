# Aditya Dhamija analyst portfolio

Responsive static portfolio for business analyst, business intelligence, operations analyst and planning analyst applications.

The portfolio includes an evidence room with a recruiter-facing diagnostic dashboard, selected Connect Lab slide previews, and links to the supplied Connect Lab and JCPenney presentation files.

## Preview locally

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publishing

The site has no build step and can be deployed to GitHub Pages, Netlify or another static host. The copy is based on the supplied CV, reports, notebooks, presentation and stated MAAI 2026 project facts. The Twosides repository link is relative while the two folders sit together; replace it with the final public GitHub URL after publication.
